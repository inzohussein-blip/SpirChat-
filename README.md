# SpirChat

منصة تواصل مفتوحة المصدر تجمع بين **المحادثات** (مثل واتساب) و**المنشورات والصور** (مثل إنستغرام).
صُممت لتعمل عند **انقطاع الإنترنت** عبر محطات واي فاي محلية، والإنترنت الداخلي، وبنقل الرسائل من هاتف
إلى هاتف.

An open-source, offline-first messaging and photo-sharing platform. It keeps communities connected
when internet access is cut, using local Wi-Fi hubs, domestic networks, and phones that carry messages
between hubs.

## ما يعمل الآن

- **محطة (Hub):** جهاز Raspberry Pi أو أي حاسوب يبث شبكة واي فاي، وتفتح المنصة تلقائياً لأي هاتف يتصل به.
- **تطبيق ويب** يعمل على أي هاتف (أندرويد وآيفون) دون تثبيت، وواجهته عربية:
  - **الرئيسية:** منشورات مع صور مضغوطة تلقائياً.
  - **الغرف:** محادثات جماعية عامة حسب الحي أو الموضوع.
  - **المحادثات الخاصة:** مشفّرة من طرف إلى طرف، والوسيط لا يعرف المرسل.
  - **الاستغاثة (SOS)** و**التنبيهات الموثّقة**، وكلاهما بأعلى أولوية.
  - **هوية بلا رقم هاتف:** مفتاح يُنشأ على الجهاز، مع رمز استعادة.
- **الحمل التلقائي:** كل هاتف يحمل الرسائل ويسلّمها لأي محطة أخرى يتصل بها.
- **ربط المحطات** عبر أي شبكة IP، أو **يدوياً** بنقل ملف على فلاشة أو هاتف.

## التشغيل محلياً

يتطلب Node.js 22.18 أو أحدث.

```bash
npm install
npm run build          # بناء تطبيق الويب
PORT=8080 npm start    # تشغيل المحطة ← افتح http://localhost:8080
```

أوامر التطوير:

```bash
npm test               # اختبارات البروتوكول والمحطة
npm run typecheck
npm run dev:hub        # المحطة على المنفذ 8080
npm run dev:web        # الواجهة مع إعادة التحميل التلقائي (توجّه الطلبات للمحطة)
```

## هيكل المستودع

```
packages/protocol   مكتبة البروتوكول المشتركة: الهويات، التشفير، الظروف، إثبات العمل
hub                 خادم المحطة: Node.js و SQLite و WebSocket
web                 تطبيق الويب: Preact و Vite
deploy/raspberry-pi سكربت التركيب وخدمة systemd
```
