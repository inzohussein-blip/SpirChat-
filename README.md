# SpirChat

منصة تواصل مفتوحة المصدر تجمع بين **المحادثات** (مثل واتساب) و**المنشورات والصور** (مثل إنستغرام)،
مصممة لتعمل عند **انقطاع الإنترنت العالمي** عبر الإنترنت الداخلي، والمحطات المحلية، والواي فاي،
والبلوتوث، والراديو بعيد المدى.

An open-source, offline-first messaging and photo-sharing platform built to keep communities
connected when global internet access is cut — over domestic networks, local Wi-Fi hubs,
phone-to-phone mesh (Bluetooth / Wi-Fi Direct), and long-range radio.

## الحالة

المشروع في مرحلة التخطيط. راجع **[خطة المشروع](docs/PLAN.md)** للمعمارية والمقترحات وخارطة الطريق.

## المبادئ

- **خزّن ثم مرّر**: كل رسالة تصل في النهاية عبر أي مسار متاح، حتى لو تأخرت.
- **بلا خادم مركزي إجباري**: الهوية مفتاح على جهازك، لا رقم هاتف.
- **تشفير من طرف إلى طرف**: الوسطاء لا يعرفون المحتوى ولا المرسل.
- **محلي أولاً**: المحطة تخدم أي هاتف عبر المتصفح، والتطبيق يضيف شبكة Mesh.
