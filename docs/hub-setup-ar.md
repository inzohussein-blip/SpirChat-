# دليل تركيب محطة SpirChat

المحطة جهاز صغير يبث شبكة واي فاي مفتوحة. أي هاتف يتصل بها تفتح له المنصة تلقائياً،
فيتواصل مع كل من يتصل بنفس المحطة، وبالمحطات الأخرى المرتبطة بها، دون إنترنت.

## 1. القطع المطلوبة

| القطعة | ملاحظات |
|---|---|
| Raspberry Pi 4 أو 5 (ذاكرة 2GB أو أكثر) | أو أي حاسوب محمول قديم بنظام لينكس |
| بطاقة microSD بسعة 32GB أو أكثر | |
| شاحن 5V/3A **ومعه بطارية احتياطية (UPS) أو باوربانك** | ضروري بسبب انقطاع الكهرباء الوطنية |
| (اختياري) راوتر خارجي بهوائي قوي | الواي فاي المدمج في الـ Pi يغطي 20–50 متراً فقط. راجع القسم 4 |

## 2. التركيب (يتطلب إنترنت مرة واحدة فقط)

1. احرق **Raspberry Pi OS Lite (64-bit)** على البطاقة بواسطة Raspberry Pi Imager، وفعّل SSH.
2. ادخل على الـ Pi ونفّذ:

```bash
sudo apt-get install -y git rsync
git clone https://github.com/inzohussein-blip/SpirChat-.git spirchat
cd spirchat
sudo HUB_NAME=Karrada-1 ./deploy/raspberry-pi/setup.sh
```

3. أعد التشغيل. ستظهر شبكة واي فاي باسم `SpirChat-Karrada-1`.
4. اتصل بها من هاتفك. يفترض أن تفتح صفحة المنصة تلقائياً. إن لم تفتح، افتح `http://10.42.0.1` في المتصفح.

> ⚠️ لم يُختبر سكربت التركيب بعد على جهاز Raspberry Pi حقيقي. سجّل أي خطأ يظهر لك.

### إعدادات اختيارية

| المتغير | المعنى | مثال |
|---|---|---|
| `HUB_NAME` | اسم المحطة كما يظهر للمستخدمين | `Mosul-Old-City` |
| `CHANNEL` | قناة الواي فاي (1 أو 6 أو 11). اختر الأقل ازدحاماً | `11` |
| `PEERS` | عناوين محطات أخرى للمزامنة معها، مفصولة بفواصل | `http://10.0.5.1,http://192.168.8.20` |
| `ALERT_KEYS` | هويات الجهات المسموح لها بنشر **تنبيهات موثّقة** | تُنسخ من صفحة «أنا» في التطبيق |

## 3. ربط المحطات ببعضها

المحطة تستطيع المزامنة مع أي محطة أخرى يصل إليها **أي اتصال IP**:

- **الإنترنت الداخلي:** عند قطع الكابلات الدولية تبقى الشبكات الداخلية لشركات الاتصالات العراقية
  تعمل أحياناً. إن كانت للمحطتين عناوين يصل بعضها لبعض، ضع العنوان في `PEERS` على الطرفين.
- **واي فاي نقطة لنقطة:** يربط زوج من أجهزة CPE الخارجية الموجّهة (Ubiquiti أو TP-Link CPE/Pharos)
  حيين بينهما خط نظر مباشر، لمسافة 5–15 كم. وصّل كل جهاز بمنفذ Ethernet في الـ Pi.
- **النقل اليدوي:** من صفحة «أنا» ← «تنزيل حزمة بيانات المحطة». احمل الملف على هاتف أو فلاشة إلى
  محطة أخرى، ثم «رفع حزمة إلى المحطة».
- **تلقائياً عبر الناس:** كل هاتف استخدم المنصة يحمل نسخة من الرسائل، وعند اتصاله بمحطة أخرى
  يسلّمها إليها تلقائياً. الرسائل الخاصة تبقى مشفّرة.

## 4. توسيع التغطية

- يكفي هوائي الـ Pi الداخلي لغرفة أو قاعة.
- لتغطية شارع أو حي: عطّل الواي فاي في الـ Pi، ووصّله بكابل Ethernet إلى راوتر أو Access Point خارجي
  مرفوع على سطح. اضبط الراوتر على وضع **Access Point / Bridge** بشبكة مفتوحة، واجعل DHCP وDNS
  من الـ Pi. (دليل هذا الإعداد بالتفصيل قادم في الإصدار التالي.)

## 5. الصيانة

```bash
journalctl -u spirchat-hub -f          # السجلات
curl http://10.42.0.1/api/info         # الإحصائيات
sudo systemctl restart spirchat-hub    # إعادة التشغيل
```

البيانات محفوظة في `/var/lib/spirchat/hub.db`. الرسائل منتهية الصلاحية تُحذف تلقائياً. إن امتلأت
المساحة تُحذف الصور القديمة أولاً، وتبقى النصوص والاستغاثات.

## 6. ملاحظات أمنية

- الشبكة **مفتوحة عمداً** حتى يتصل أي شخص بسهولة. المحتوى العام (المنشورات والغرف والاستغاثات)
  يراه الجميع. الرسائل الخاصة مشفّرة من طرف إلى طرف، ولا يستطيع مشغّل المحطة قراءتها.
- مشغّل المحطة يرى عناوين الأجهزة المتصلة وأوقات الاتصال. لا تُشغّل محطة في مكان يعرّضك للخطر.
- البث اللاسلكي يمكن تحديد مكانه بأجهزة رصد.
