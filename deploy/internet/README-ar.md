# تشغيل محطة إنترنت

محطة الإنترنت هي برنامج المحطة نفسه، لكنه يعمل على خادم سحابي له اسم نطاق (domain) وشهادة HTTPS.
عندما يتوفر الإنترنت يتصل بها التطبيق تلقائياً، فتصل الرسائل بين الأحياء والمدن والعالم. والمحطات
المحلية التي لديها اتصال إنترنت تزامن نفسها معها.

## المتطلبات

- خادم لينكس صغير (1 معالج، 1GB ذاكرة) من أي مزوّد سحابي.
- اسم نطاق، مثل `hub.example.org`، يشير سجل DNS من نوع A فيه إلى عنوان الخادم.
- Docker مثبّت على الخادم.

## التشغيل

```bash
git clone https://github.com/inzohussein-blip/SpirChat-.git spirchat
cd spirchat/deploy/internet
DOMAIN=hub.example.org docker compose up -d --build
```

- يحصل Caddy على شهادة HTTPS تلقائياً ويجددها.
- افتح `https://hub.example.org` للتأكد أن المنصة تعمل.

## ربط التطبيقات والمحطات بها

- **التطبيق والمتصفح:** صفحة «أنا» ← «الإنترنت» ← أضف `https://hub.example.org`.
- **جعلها افتراضية في كل نسخ التطبيق:** في إعدادات المستودع على GitHub
  (Settings ← Secrets and variables ← Actions ← Variables) أضف متغيراً باسم `SPIRCHAT_INTERNET_HUBS`
  قيمته `https://hub.example.org`. كل نسخة APK تُبنى بعدها تتصل بها تلقائياً.
- **محطة محلية لديها إنترنت:** شغّلها مع `PEERS=https://hub.example.org`. ولتصلها رسائل المحطة
  المحلية أيضاً، أضف عنوانها في `PEERS` على محطة الإنترنت، إن كانت المحطة المحلية قابلة للوصول من الإنترنت.

## إعدادات

| المتغير | المعنى |
|---|---|
| `DOMAIN` | اسم النطاق (مطلوب) |
| `HUB_NAME` | الاسم الظاهر للمستخدمين |
| `PEERS` | محطات أخرى تزامن معها هذه المحطة |
| `ALERT_KEYS` | هويات الجهات المسموح لها بنشر تنبيهات موثّقة |
| `MAX_STORE_MB` | الحد الأقصى للتخزين (الافتراضي 8192) |

## ملاحظات أمنية

- المحطة لا تستطيع قراءة الرسائل الخاصة ولا معرفة مرسلها، لكنها ترى عناوين IP لمن يتصل بها، وكذلك
  مزوّد الخادم.
- اختر مزوّد خادم ومكاناً لا يعرّض المستخدمين للخطر.
- في العراق قد يُحجب نطاق المحطة. تعدد محطات الإنترنت في التطبيق يقلل أثر حجب واحدة منها.
